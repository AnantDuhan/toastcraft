# Changelog

All notable changes to toastcraft are documented here.

## [0.1.1] - 2026-10-05

### Added

- 15 built-in toast designs.
- Framework-agnostic TypeScript API.
- Promise-based loading/success/error toasts.
- Actions, progress bars and swipe dismissal.
- Queue and overflow controls.
- Custom design registration.
- SSR-safe imports.
- Accessibility and reduced-motion support.
- Interactive playground.

### Notes

This is the initial public release and the API is still evolving toward 1.0.0.
