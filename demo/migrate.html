Move from ngx-toastr to ngx-toastcraft

Most apps switch in a few minutes. You keep the same idea, a provider and an injectable service, and get 15 designs, component toasts and an HTTP error interceptor.

  • Angular 18 to 22
  • No CSS import
  • No @angular/animations
  • Works with or without zone.js

1Swap the packages

Uninstall ngx-toastr and install ngx-toastcraft.

npm uninstall ngx-toastr
npm i ngx-toastcraft

Remove the ngx-toastr stylesheet from angular.json

ngx-toastcraft injects its own styles, so there's nothing to add back.

"styles": [
  "src/styles.css",
  "node_modules/ngx-toastr/toastr.css"
]

2Swap the provider

With NgModules, put provideToastcraft() in the module's providers where ToastrModule.forRoot() was.

Before

import { provideToastr } from 'ngx-toastr';

provideToastr({
  timeOut: 5000,
  positionClass: 'toast-bottom-right',
  progressBar: true,
});

After

import { provideToastcraft } from 'ngx-toastcraft';

provideToastcraft({
  duration: 5000,
  position: 'bottom-right',
  progress: true,
});

3Swap the service and flip the arguments

ngx-toastr takes the message first and the title second. ngx-toastcraft takes the title first, with the message as description. If you only pass one argument, the call stays the same.

Before

private toastr = inject(ToastrService);

this.toastr.success(
  'Your profile is up to date.',
  'Saved',
);
this.toastr.error('Upload failed');

After

private toast = inject(ToastService);

this.toast.success('Saved', {
  description: 'Your profile is up to date.',
});
this.toast.error('Upload failed');

4Check two behavior changes

These defaults differ from ngx-toastr. Keep the old behavior with one option each.

  • Clicking a toast no longer closes it.Add closeOnClick: true to provideToastcraft() to keep ngx-toastr's tap-to-dismiss.
  • Toasts show a close button by default.Add dismissible: false to hide it.

New things you get

Optional, but worth a look once the switch is done.

A toast on every failed HTTP request

import { toastcraftHttpErrors } from 'ngx-toastcraft';

provideHttpClient(
  withInterceptors([toastcraftHttpErrors()]),
);

Loading, then success or error, for an Observable

this.http.post('/api/reports', report).pipe(
  this.toast.track({
    loading: 'Saving report…',
    success: 'Report saved',
    error: 'Could not save the report',
  }),
).subscribe();
