# Angular workspace

This folder holds the Angular adapter, [`ngx-toastcraft`](./projects/ngx-toastcraft/README.md), and a demo app that uses every feature.

```bash
cd angular
npm install
npm run test:lib      # unit tests
npm run demo          # build the library and serve the demo at http://localhost:4200
npm run publish:lib   # test, build and publish ngx-toastcraft to npm
```
